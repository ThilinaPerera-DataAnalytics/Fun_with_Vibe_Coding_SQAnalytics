# SQAnalytics

Smart QR Analytics Platform

![project logo](/main_logo.png)

SQAnalytics is a Full Stack Analytics Platform designed to transform printed QR interactions into measurable digital engagement.

## Vision

QR Scan
→ Analytics Tracking
→ Redirect Engine
→ Author Website
→ Embedded Content

## Objectives

- QR Code Management
- Redirect Infrastructure
- Analytics Tracking
- Reporting Dashboard
- Portfolio-Grade Full Stack Project

## Tech Stack

- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- Hosting: Render
- Source Control: GitHub
